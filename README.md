# Better Fonts

**Say goodbye to Minecraft's blurry, unreadable default text! This mod effortlessly replaces it with high-quality Google Fonts, giving you the complete freedom to customize your in-game typography.**

## Features
* **Google Fonts Integration:** Access a massive library of clean, modern, and highly readable fonts directly in-game.
* **Complete Customization Freedom:** Easily choose and apply your favorite fonts to perfectly match your UI style.
* **Next-Gen QoL Improvement:** Enjoy pixel-perfect, ultra-smooth rendering that surpasses traditional font mods.

## Technical Details
* **Side:** Client-side only
* **Mod Loader:** Fabric
* **Minecraft Version:** 1.21.11-26.3
